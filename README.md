# Nitish Yadav — Academic Website

Static academic website for Nitish Yadav.

## Pages
- `index.html` — profile, biography, research interests, education, publications, and contact
- `teaching.html` — teaching-assistant experience
- `publication.html` — journal and conference publications

## Preview locally
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000`.

The site is static and can be deployed directly with GitHub Pages.
